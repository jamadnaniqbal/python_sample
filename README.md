🔤 String Vowel & Consonant Counter

A simple Python project that analyzes a given string and identifies vowels and consonants. This project is beginner-friendly and demonstrates basic Python concepts such as strings, loops, conditions, and user input.

🚀 Features

Takes a string as input from the user

Identifies vowels (a, e, i, o, u)

Identifies consonants

Counts the number of vowels and consonants

Ignores spaces and special characters

🛠️ Technologies Used

🐍 Python 3
